## 🧩 What Is It?

**Search Problems in Virtual Reality** is an educational VR application designed to make search algorithms more tangible and interactive.

Instead of learning search algorithms only through diagrams and pseudocode, players can **explore search problems in 3D**, interact with them, and watch algorithms solve them step by step.

The project was developed for **Meta Quest 3S** using Unity and OpenXR.

---

## ✨ Features

* 🧠 **6 search algorithms**

  * Breadth-First Search (BFS)
  * Depth-First Search (DFS)
  * Iterative Deepening Search (IDS)
  * Uniform-Cost Search (UCS)
  * Greedy Best-First Search (GBFS)
  * A* Search

* 🕹️ **Interactive VR search problems**

* 👀 **Step-by-step algorithm visualization**

* 🎮 **Manual solving mode** with feedback

* 🗺️ 3D maze-based search environments

* 📚 Multiple predefined problems with different configurations

* 🥽 Designed for **Meta Quest 3S**

---

## 🎮 How It Works

Players are presented with a search problem inside a VR environment.

They can either:

**Solve:**
Navigate the environment themselves while applying what they learned about search algorithms.

**Observe:**
Select an algorithm and watch its search process unfold step by step.

The goal is to connect the abstract concepts behind search algorithms with a spatial, interactive representation.

## 📊 Evaluation

The application was evaluated with **16 participants** as part of the bachelor thesis.

| Measure                 |          Result |
| ----------------------- | --------------: |
| Average pre-test score  |       21.2 / 34 |
| Average post-test score |       25.8 / 34 |
| Average improvement     |           +4.67 |
| System Usability Scale  | **80.16 / 100** |

The study showed an improvement in participants' test scores after using the application, while the thesis notes that a larger study would be needed to draw stronger conclusions about learning effectiveness.

## 🚧 Current Scope

The current version focuses on **grid-based maze pathfinding**.

The search system was designed to support additional search problem types in the future, such as:

* 8-puzzle
* Rubik's Cube
* Problems with varying step costs
